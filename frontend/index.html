DarkChecker

Seus dados estão à venda no mundo sem leis?

Projeto acadêmico · uso não comercial

Digite um e-mail para descobrir em quais vazamentos de dados públicos ele já apareceu. Cruzamos apenas fontes legítimas (XposedOrNot e LeakCheck, gratuitas; e opcionalmente Have I Been Pwned).

🔒 O e-mail é usado apenas para a consulta e não é armazenado por esta aplicação.

Verifique se uma senha já vazou — sem nunca enviá-la pela rede. Usamos k-anonimato: só os 5 primeiros caracteres do hash SHA-1 saem do servidor. Entenda a técnica →

🔒 A senha nunca é armazenada nem enviada por completo. Ainda assim, evite digitar sua senha real — use uma de teste.

Carregando conteúdo educacional…

DarkChecker — desenvolvido para fins acadêmicos. Utiliza apenas dados de vazamentos já indexados por serviços legítimos de segurança. Nenhum dado é raspado da dark web por esta aplicação.

Fontes: XposedOrNot · LeakCheck · Have I Been Pwned · Pwned Passwords (k-anonimato)
