# Declaração de Ética e Uso Responsável

O **DarkChecker** é um artefato **acadêmico**, desenvolvido para demonstrar,
de forma **legal e ética**, que dados pessoais vazados circulam livremente e
que estamos expostos a isso. Esta declaração define os limites do projeto.

## O que este projeto FAZ

- Consulta **serviços legítimos** de segurança (Have I Been Pwned, XposedOrNot)
  que já indexaram vazamentos **publicamente conhecidos**.
- Trabalha exclusivamente com **metadados** de vazamento: nome do incidente,
  data e *categorias* de dado expostas.
- Verifica senhas por **k-anonimato**, de modo que a senha **nunca** é
  transmitida à rede.
- Não armazena o e-mail nem a senha consultados.

## O que este projeto NÃO FAZ (por decisão de projeto)

- ❌ **Não** faz *crawling* da dark web nem de fóruns/mercados de dados roubados.
- ❌ **Não** baixa, armazena, processa ou redistribui *dumps* de credenciais
  roubadas.
- ❌ **Não** expõe senhas, hashes ou dados pessoais de terceiros.
- ❌ **Não** acessa nenhum sistema sem autorização.

## Por que essa fronteira existe

Raspar dumps da dark web exigiria **acessar e manusear dados obtidos
ilicitamente** — conduta que pode configurar crime **independentemente da
intenção acadêmica** (no Brasil, Leis 12.737/2012 e 14.155/2021; nos EUA, a
CFAA), além de perpetuar o dano às vítimas dos vazamentos.

Metodologicamente, a tese do trabalho — *"a dark web é um ambiente onde a lei
tem alcance limitado e estamos sujeitos a isso"* — fica **mais bem defendida**
usando a metodologia legítima da indústria de segurança: demonstra-se o problema
**e** a resposta ética a ele, sem reproduzir o crime que se pretende denunciar.

## Uso responsável esperado

- Consulte apenas **o seu próprio e-mail** ou o de pessoas que **consentiram**
  explicitamente (ex.: contas de teste).
- **Não** reutilize os resultados para constranger, expor ou atacar terceiros.
- Respeite os Termos de Uso e os limites de taxa das APIs consultadas.
- Trate qualquer resultado como informação sensível.

## Isenção

Este software é fornecido "como está", para fins **educacionais e não
comerciais**. Os autores não se responsabilizam por uso indevido. O conteúdo
legal aqui apresentado é informativo e **não constitui aconselhamento
jurídico**.
